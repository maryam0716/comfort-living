# Comfort Living

A full-stack e-commerce website for Comfort Living.

## Project Structure

- Frontend: React + Vite
- Backend: Node.js + Express

## Features

- Product catalogue
- Categories
- Shopping cart
- User authentication
- Admin dashboard
- Responsive design

## Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```
